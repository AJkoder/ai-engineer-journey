# NumPy Learning

This folder contains practical NumPy examples from the AI Engineer roadmap.

## Learning order

1. `intro.py` — Introduction to NumPy
2. `01_arrays_and_dimensions.py` — Dimensions, shape and size
3. `02_array_creation.py` — Creating arrays
4. `03_indexing_and_slicing.py` — Accessing array elements
5. `04_reshaping_and_axes.py` — Reshaping, flattening, transpose and axes
6. `05_broadcasting.py` — Broadcasting rules
7. `06_mathematical_operations.py` — Mathematical operations
8. `07_statistical_operations.py` — Statistical functions
9. `08_matrix_operations.py` — Matrix calculations
10. `09_numpy_practice.py` — Practice exercises
11. `10_numpy_mini_project.py` — HeartTalk feedback analysis

## Run a file

From the repository root:

```bash
python phase2/numpy/intro.py
python phase2/numpy/01_arrays_and_dimensions.py
```

Run any other file by replacing the filename.

## Prerequisite

Activate your project virtual environment and install NumPy if needed:

```bash
pip install numpy
```

## Learning rule

Understand the concept first, run the example, predict the output, and then modify the code yourself.\n
